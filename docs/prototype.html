WHY

2年間練習を重ねてカラオケで90点を超えたものの、採点は音程やリズムの正確さが中心で、歌に込めた想いまでは映しきれないと感じました。似たサービスが見つからなかったので、自分で作ることにしました。

WHAT

歌声を録音・アップロードすると、音程・リズム・ビブラートなどの技法を分析してスコアで返します。結果はユーザーごとに保存し、ダッシュボードで推移を見られます。

HOW

  • 音声処理のライブラリがそろう Python / FastAPI でバックエンドを構成。Crepe でピッチ検出、librosa で特徴量抽出、Demucs でボーカル分離
  • 分析は重いので Celery + Redis で非同期化し、ユーザーを待たせない作りに
  • 録音データは保存せず、分析後に削除（著作権とプライバシーへの配慮）
  • 実装は生成 AI を活用。機能の分解・判断・動作確認は自分で行い、機能ごとに issue を分けて進めています

NOW・NEXT

録音から分析・結果表示までは動作しています。いまは分析の精度を最優先に、リズムとピッチ評価の不具合を修正中。将来は、歌に込めた感情を別の軸で数値化することに挑戦したいと考えています。
